Um Tipo Documental categoriza os documentos produzidos pela organizacao. Ele define a natureza do documento (relatorio, pedido, oficio etc.) e sua distribuicao (interno, externo ou hibrido), o que determina automaticamente se o documento pode ser difundido internamente, externamente ou em ambos os sentidos. Os templates documentais sao vinculados a tipos documentais.
