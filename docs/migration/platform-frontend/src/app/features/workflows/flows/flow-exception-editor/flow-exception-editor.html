Excecoes do Fluxo

Uma excecao substitui ou complementa uma regra geral para combinacoes especificas de origem e destino. Use excecoes para tratar casos como: um setor administrativamente externo que e funcionalmente autorizado a receber documentos, ou uma vedacao absoluta para uma combinacao especifica. Excecoes tem prioridade sobre as regras gerais.
