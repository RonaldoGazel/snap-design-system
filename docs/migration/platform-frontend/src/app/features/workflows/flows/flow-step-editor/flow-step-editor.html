Etapas do Fluxo

Uma etapa representa um estado do documento dentro do fluxo — por exemplo, "workflows.docStatus.inProduction", "workflows.docStatus.inReview" ou "workflows.docStatus.formalized". Cada etapa tem um tipo que define o que pode acontecer nela e um papel responsável principal. Após criar as etapas, vá para a aba Transições para conectá-las.
