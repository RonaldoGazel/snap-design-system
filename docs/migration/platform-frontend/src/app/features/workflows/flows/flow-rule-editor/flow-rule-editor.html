Regras do Fluxo

As regras controlam quem pode executar cada acao no fluxo. Uma regra de Criacao define quem pode iniciar um documento. Uma regra de Tramitacao define quem pode enviar e para quem. Uma regra de Difusao define quem pode distribuir o documento. Cada regra tem uma origem (quem age) e um destino (para quem), ambos definidos por combinacao de unidade + perfil.
