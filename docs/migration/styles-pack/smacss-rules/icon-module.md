# The Icon Module
Icons should be treated as reusable modules with their own states and variations, rather than just images.

## Key Concepts
- **Base Icon Class:** Define a generic `.icon` class for shared properties (dimensions, display, alignment).
- **Sub-modules:** Use specific classes for individual icons (e.g., `.icon-home`, `.icon-search`).
- **State and Size:** Use modifiers for different sizes (`.icon-large`) or states (`.icon-is-active`).
- **Implementation:** Whether using sprites, icon fonts, or SVGs, maintain SMACSS naming conventions.
