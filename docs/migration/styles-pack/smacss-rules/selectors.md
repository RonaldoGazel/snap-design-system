# Selector Performance
Browsers evaluate CSS selectors from right to left, meaning the right-most selector (the "key selector") is the first thing the browser checks. While complex descendant and qualified selectors (like `div#content`) are technically less efficient, the performance impact is often negligible (around 50ms). The chapter recommends practical guidelines: use child selectors where possible, avoid tag selectors for common elements, and ensure the right-most selector is a class or ID to help the browser filter elements quickly without over-optimizing at the cost of readability.
